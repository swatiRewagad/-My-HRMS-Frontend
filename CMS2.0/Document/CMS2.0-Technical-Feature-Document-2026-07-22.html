Assignment Algorithm

// ComplaintRoutingService.assignOfficerByRole()
public String assignOfficerByRole(String role) {
    // 1. Query Keycloak for all users with the given role
    List<String> officers = keycloakUserService.getUsersByRole(role);

    // 2. If Keycloak is unreachable or no users found → fallback
    if (officers.isEmpty()) {
        return role.replace("_", " ") + " Team"; // e.g. "RBIO OFFICER Team"
    }

    // 3. Atomic counter for round-robin (survives restarts via DB)
    int index = counter.getAndIncrement() % officers.size();

    // 4. Return selected officer's username
    return officers.get(index);
}

// Routing decision:
// WEB_PORTAL source → always RBIO (direct assignment)
// EMAIL/PHYSICAL_LETTER → CRPC first, then route based on entity type:
//   Banking entity → RBIO
//   Non-banking entity → CEPC

4. Transactional Outbox Pattern (Kafka)

Kafka Spring Boot Oracle

How It Works

  1. Write phase: Business service saves complaint data + outbox event in same DB transaction
  2. Poll phase: cms-outbox-publisher polls OUTBOX_EVENTS table every 5 seconds
  3. Publish phase: Publishes events to Kafka topics
  4. Mark phase: Updates status to PUBLISHED in DB
  5. Retry: Max 5 retries with exponential backoff
  6. DLQ: After 5 failures, moved to complaint.dlq topic

Kafka Topics

TopicProducerConsumersPurpose
complaint.ingestedOutbox PublisherAssignment, SLA, Search, Audit, NotificationNew complaint filed
complaint.assignedOutbox PublisherNotification, AuditOfficer assigned
complaint.inprogressOutbox PublisherSLA, AuditWork started
complaint.escalatedSLA MonitorNotification, AuditSLA breach escalation
complaint.resolvedOutbox PublisherNotification, Audit, SearchResolution provided
complaint.closedOutbox PublisherNotification, Audit, SearchFinal closure
complaint.dlqOutbox PublisherAdmin alertingFailed events

Outbox Table Schema

CREATE TABLE OUTBOX_EVENTS (
    id           NUMBER PRIMARY KEY,
    topic        VARCHAR2(100) NOT NULL,
    payload      CLOB NOT NULL,
    status       VARCHAR2(20) DEFAULT 'PENDING',  -- PENDING, PUBLISHED, FAILED
    retry_count  NUMBER DEFAULT 0,
    created_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    published_at TIMESTAMP,
    error_msg    VARCHAR2(500)
);

// QueryCompiler.buildAuthScope():
// - ADMIN / SENIOR roles → see ALL complaints (no filter)

return cb.conjunction(); // no filter (see all)
