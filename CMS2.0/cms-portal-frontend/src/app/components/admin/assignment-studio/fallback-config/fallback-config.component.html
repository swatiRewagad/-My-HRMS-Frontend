Distribution Strategies

ROUND_ROBIN

Cycles through eligible members in order. Maintains atomic counter per group.

LEAST_ACTIVE_CASES

Assigns to member with fewest open cases. Requires workload integration.

RANDOM

Random selection from eligible members. Good for load testing.

CAPACITY_WEIGHTED

Weighted by member capacity profile. Requires capacity data.

SKILL_MATCH

Matches member skills to case attributes. Requires skill profiles.

LANGUAGE_MATCH

Matches member language to complainant preference.
